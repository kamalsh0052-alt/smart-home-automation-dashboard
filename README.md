# 🏠 Smart Home Automation Dashboard

A Python-based dashboard for controlling and monitoring a Smart Home Automation System.

## 📌 Project Overview

This project provides a simple graphical dashboard to control home appliances such as:

- 💡 Light
- 🌀 Fan
- ❄️ AC

The dashboard also displays the current temperature and system connection status.

## 🛠️ Technologies Used

- Python
- Tkinter
- GUI Design
- IoT / Smart Home Automation

## ✨ Features

- Control Light ON/OFF
- Control Fan ON/OFF
- Control AC ON/OFF
- Temperature monitoring
- System connection status
- Simple and user-friendly interface

1. Install Python.
2. Open the project folder.
3. Open the terminal.
4. Run:
